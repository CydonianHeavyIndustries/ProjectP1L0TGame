1. LOGIN FUNCTIONALITY
================================================================================

Function Name: handleLogin(email: string, password: string)

Location: /src/app/components/LoginPage.tsx

Description:
  Called when user submits the login form. Currently has test credentials built in.

Parameters:
  - email: string (user's email address or username)
  - password: string (user's password)

Expected API Call:
  Method: POST
  Endpoint: /api/auth/login
  Request Body: 
    {
      "email": "user@example.com",
      "password": "userPassword123"
    }

Expected Response:
  Success (200):
    {
      "token": "jwt_token_here",
      "user": {
        "id": "user_id",
        "username": "username",
        "email": "user@example.com"
      }
    }
  
  Error (401):
    {
      "error": "Invalid credentials",
      "message": "Email or password is incorrect"
    }

12. DATA PERSISTENCE RECOMMENDATIONS
================================================================================

User Session:
  - Store JWT token in httpOnly cookie (most secure)
  - Alternative: localStorage (less secure but simpler)
  - Implement token refresh mechanism
  - Set appropriate expiration (e.g., 7 days with refresh)

Profile Data:
  - Fetch on login/page load
  - Cache in application state
  - Invalidate cache on updates
  - Use optimistic updates for better UX

File Uploads:
  - Implement size limits (5MB recommended for avatars)
  - Validate file types (JPG, PNG, GIF)
  - Use CDN for serving images
  - Generate thumbnails for performance

14. SECURITY CONSIDERATIONS
================================================================================

Password Requirements:
  - Minimum 8 characters (implement in frontend validation)
  - Mix of letters, numbers, symbols (optional but recommended)
  - Hash with bcrypt/Argon2 on backend

Email Verification:
  - Send verification email on signup
  - Allow login with unverified email but limit features
  - Require verification for email changes

Rate Limiting:
  - Login attempts: 5 per 15 minutes
  - Password reset: 3 per hour
  - Profile updates: 10 per hour
  - Avatar upload: 5 per hour

Input Sanitization:
  - Sanitize all text inputs (bio, username, etc.)
  - Validate URLs for social links
  - Prevent XSS attacks
  - Validate file uploads
